# pages/landing/

La structure et le texte de la page d'accueil.

## Ce qu'on met ici

- `structure.md` — les sections dans l'ordre, avec l'intention de chacune.
- `copy.md` — le texte exact, prêt à intégrer.

## Ce qu'on ne met pas ici

Du code HTML ou CSS, des maquettes visuelles (→ `assets/mockups/`).

## Règle

Chaque section de la landing répond à une objection identifiée dans `brainstorm/objections.md`. Une section qui ne répond à rien est une section à couper.
