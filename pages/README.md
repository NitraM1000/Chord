# pages/

Tout ce qui sert à présenter Chord à l'extérieur.

## Ce qu'on met ici

- `landing/` — structure et texte de la page d'accueil.
- `copy/` — taglines, pitchs 30 secondes / 2 minutes / 5 minutes.
- `deck/` — le plan du pitch deck, slide par slide.

## Ce qu'on ne met pas ici

- Le raisonnement derrière le positionnement → `docs/positioning.md`. Ici on écrit le résultat, pas la démonstration.
- Les images et exports → `assets/`.

## Règle

Une promesse écrite dans `pages/` doit être tenable par le produit décrit dans `product/`. Si l'écart est volontaire (vision affichée en avance sur le produit), il faut le noter dans le fichier.
