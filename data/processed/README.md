# data/processed/

Les données nettoyées, prêtes à l'analyse.

## Ce qu'on met ici

Le résultat des scripts de traitement appliqués à `raw/`.

## Ce qu'on ne met pas ici

Des fichiers produits par une manipulation manuelle non reproductible.

## Règle

Chaque fichier ici indique en tête (ou dans un `.md` associé) quel script l'a produit et à partir de quelle source. Si on ne peut pas régénérer le fichier, il n'a pas sa place ici.
