# research/surveys/

Les questionnaires quantitatifs et leurs résultats.

## Ce qu'on met ici

- Le questionnaire tel qu'il a été envoyé (`questions.md`).
- Les résultats agrégés et leur lecture (`results-*.md`).
- Le contexte : combien de répondants, comment recrutés, sur quelle période.

## Ce qu'on ne met pas ici

- Les réponses individuelles avec des données identifiantes → `private/`.
- Les exports bruts volumineux → `data/raw/`.

## Règle

Un résultat d'enquête sans taille d'échantillon ni méthode de recrutement n'est pas exploitable. On indique toujours les deux, et on assume les biais quand l'échantillon est petit ou non représentatif — ce qui sera le cas au début.
