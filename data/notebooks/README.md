# data/notebooks/

Les analyses exploratoires.

## Ce qu'on met ici

Notebooks Jupyter ou scripts d'analyse, nommés `NN-sujet.ipynb` pour garder l'ordre de lecture.

## Ce qu'on ne met pas ici

- Des notebooks avec des sorties contenant des données personnelles. **On vide les sorties avant de commiter.**
- Du code de production → `scripts/`.

## Règle

Un notebook est un brouillon d'analyse. Dès qu'un traitement doit être rejoué régulièrement, il devient un script dans `scripts/`.
