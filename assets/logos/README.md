# assets/logos/

Le logo Chord et ses déclinaisons.

## Ce qu'on met ici

- Le SVG source (référence, toujours à jour).
- Les exports PNG en `@1x` et `@2x`.
- Les variantes `light`, `dark`, `mono`.

## Ce qu'on ne met pas ici

Des versions modifiées à la main sans passer par le SVG source, des logos de concurrents (→ `research/competitors/` si vraiment nécessaire, en respectant leurs droits).

## Convention de nommage

`chord-logo-<variante>@<densite>.<ext>` — `chord-logo-mono.svg`, `chord-logo-dark@2x.png`.
