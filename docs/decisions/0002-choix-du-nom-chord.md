# 0002 — Choix du nom « Chord »

- **Date** : 2026-07-16
- **Statut** : Acceptée
- **Décideurs** : porteur du projet

> Sources d'origine : `chord_project_files_CHOIX_FINAL.md`, `chord_project_files_NOM.md`, juillet 2026.

## Contexte

Le projet a été conçu sous le nom de travail **Bump**, qui évoquait la collision fortuite entre deux personnes. Le nom devait être arrêté avant la production de tout support de communication.

## Options envisagées

### Option A — Bump

Le nom de travail initial.

- Pour : évoque directement le contact fortuit, court, mémorisable.
- Contre : déjà utilisé par plusieurs produits, dont une application de partage de contacts par choc de téléphones — l'association est encombrée. Le mot évoque le choc, pas ce qui en résulte.

### Option B — Chord

- Pour : porte l'idée de combinaison. Un accord musical, ce sont plusieurs notes jouées ensemble qui produisent quelque chose qu'aucune ne produirait seule. La métaphore décrit exactement la promesse : ni l'un, ni l'autre — les deux ensemble.
- Contre : lien avec le produit moins immédiat que Bump ; proche de « cord » à l'oral en anglais ; en français, la prononciation n'est pas évidente pour tout le monde.

## Décision

Le projet s'appelle **Chord**.

## Raison

La métaphore de l'accord décrit la valeur produite par la rencontre plutôt que le mécanisme de la rencontre. Elle vieillit mieux : si le déclencheur du produit évolue, le nom reste juste.

Le nom se raccroche également aux cinq valeurs retenues pour le projet : spontanéité, proximité, rencontre, opportunité, authenticité.

## Conséquences

- Le nom « Bump » ne doit plus apparaître dans les documents produits après cette décision. Il subsiste dans les fichiers de recherche d'origine, conservés tels quels.
- TODO: vérifier la disponibilité du nom — marque déposée, nom de domaine, disponibilité sur les magasins d'applications. **Aucune de ces vérifications n'a été faite.** Tant qu'elles ne le sont pas, la décision est acceptée mais fragile.

## Ce qui nous ferait revenir dessus

- Une antériorité de marque sur un secteur proche.
- Un test de mémorisation raté : si les gens ne retiennent pas le nom après l'avoir entendu une fois, ou le confondent systématiquement avec autre chose.
