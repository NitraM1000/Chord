# research/peer-review/

Les retours reçus sur le projet : camarades, enseignants, professionnels, jurys.

## Ce qu'on met ici

- Un fichier par session de retour, daté.
- Le retour tel qu'il a été formulé, y compris ce qui fait mal à lire.
- Ce qu'on en fait : ignoré, à creuser, intégré (et où).

## Ce qu'on ne met pas ici

Le nom complet de la personne qui a donné le retour si elle ne l'a pas explicitement accepté. On écrit son rôle : « enseignant en entrepreneuriat », « fondateur, secteur X ».

## Règle

Un retour qu'on décide d'ignorer se note quand même, avec la raison. C'est ce qui permet de repérer plus tard qu'on a ignoré trois fois la même objection.
