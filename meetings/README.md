# meetings/

Les comptes rendus de réunion.

## Ce qu'on met ici

Un fichier par réunion : `YYYY-MM-DD-sujet.md`, à partir de `template.md`.

## Ce qu'on ne met pas ici

- Les noms complets des participants externes → « un fondateur du secteur média », « une conseillère financement public ».
- Les décisions structurantes en tant que telles : elles sont **aussi** consignées dans `docs/decisions/`. Le compte rendu note qu'elle a été prise, la décision elle-même vit dans `docs/decisions/`.

## Règle

Un compte rendu sans section « actions » avec un responsable et une échéance ne sert à rien. C'est la seule partie qu'on relit.
