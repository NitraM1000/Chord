# assets/screenshots/

Les captures d'écran.

## Ce qu'on met ici

Captures du produit, captures de concurrents pour illustrer une analyse, captures d'outils utilisés.

## Ce qu'on ne met pas ici

**Toute capture contenant des données personnelles** : noms de personnes réelles, emails, numéros, photos de profil identifiables, contenu de messages privés. On floute avant de commiter, ou on ne commite pas.

## Convention de nommage

`<sujet>-<contexte>-YYYY-MM-DD.png` — exemple : `linkedin-feed-comparison-2026-07-25.png`.
