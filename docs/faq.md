# FAQ

Les questions qui reviennent, avec des réponses courtes. Quand une réponse devient longue, elle part dans un document dédié et la FAQ y renvoie.

## Sur le projet

**C'est quoi Chord, en une phrase ?**
Une application qui révèle les connexions professionnelles utiles physiquement présentes autour de soi, à l'instant présent. Voir `docs/vision.md`.

**Où en est le projet ?**
Au stade de la recherche produit. Aucune ligne de code, aucun entretien exploitable, aucune validation. Le dépôt sert à structurer le travail de validation avant de construire quoi que ce soit.

**Pourquoi « Chord » ?**
Voir `docs/decisions/0002-choix-du-nom-chord.md`.

**Pourquoi le nom « Bump » apparaît dans certains fichiers ?**
C'était le nom de travail initial. Il subsiste dans les fichiers de recherche d'origine, conservés tels quels par honnêteté documentaire. Voir `docs/glossary.md`.

## Sur le produit

**En quoi c'est différent de LinkedIn ?**
LinkedIn gère le réseau déclaré et durable, sur un mode asynchrone. Chord vise le réseau latent et immédiat. Voir le tableau de `docs/positioning.md`.

**C'est une application de rencontre ?**
Non, le contexte visé est professionnel. Cela dit, l'objection existe et mérite mieux qu'un démenti — voir `brainstorm/objections.md`.
