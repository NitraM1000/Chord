# business/

Comment le projet tient économiquement.

## Ce qu'on met ici

- `business-model.md` — qui paie, pour quoi, comment.
- `pricing.md` — les niveaux de prix envisagés et leur justification.
- `go-to-market.md` — comment on atteint les premiers utilisateurs.
- `metrics.md` — les KPI et leur méthode de mesure.

## Ce qu'on ne met pas ici

- **Des chiffres financiers confidentiels.** Le repo est public. Les projections réelles, les échanges avec des investisseurs, les devis, les données bancaires vont dans `private/`.
- Des hypothèses de revenus présentées comme des faits.

## Règle

Toute projection financière porte la mention de ses hypothèses de départ. « 1000 utilisateurs payants en an 1 » n'a aucune valeur sans le raisonnement qui y mène.
