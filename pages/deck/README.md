# pages/deck/

Le pitch deck, en texte.

## Ce qu'on met ici

- `outline.md` — une section par slide : le message, ce qu'on montre, ce qu'on dit à l'oral.

## Ce qu'on ne met pas ici

Les fichiers `.pptx` ou `.pdf` exportés (→ `assets/`), les visuels (→ `assets/mockups/`).

## Règle

Un slide = un message. Si on n'arrive pas à écrire le message d'un slide en une phrase, le slide n'est pas prêt.
