# brainstorm/archive/

Le cimetière des idées, avec les épitaphes.

## Ce qu'on met ici

Un fichier par idée abandonnée : ce que c'était, pourquoi ça semblait bien, pourquoi on l'a écartée, et à quelle condition on la reconsidérerait.

## Ce qu'on ne met pas ici

Des idées simplement pas prioritaires. Celles-là restent dans `ideas.md` avec une note. L'archive est pour ce qui est **écarté**, pas pour ce qui attend.

## Convention de nommage

`YYYY-MM-titre-de-l-idee.md`

## Règle

La ligne la plus importante d'un fichier d'archive est « ce qui nous ferait changer d'avis ». Sans elle, on ne sait pas relire l'archive quand le contexte change.
