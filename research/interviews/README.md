# research/interviews/

Les entretiens utilisateurs, anonymisés.

## Ce qu'on met ici

- `interview-guide.md` — les questions qu'on pose et pourquoi.
- `recruitment-message.md` — le message de prise de contact.
- `interviewee-NN.md` — un fichier par entretien, anonymisé.
- `synthesis.md` — la synthèse transversale, mise à jour après chaque entretien.

## Ce qu'on ne met pas ici

- Les noms, emails, téléphones, comptes sociaux des personnes interviewées. Jamais. La correspondance `interviewee-NN` ↔ personne réelle vit dans `private/interviewees.md`, ignoré par Git.
- Les enregistrements audio ou vidéo.

## Convention de nommage

`interviewee-NN.md`, numérotation incrémentale, jamais réattribuée même si un entretien est retiré.

## Règle d'anonymisation

On retire : nom, prénom, email, téléphone, nom d'entreprise si elle est identifiante, ville si elle est trop précise combinée au reste. On garde : le profil (« fondatrice, ~28 ans, secteur média, France »), les verbatims, les faits.
