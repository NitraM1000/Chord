# assets/mockups/

Les maquettes et prototypes visuels.

## Ce qu'on met ici

Exports d'écrans, wireframes, prototypes cliquables (lien + capture).

## Ce qu'on ne met pas ici

Les fichiers source d'outils de design (Figma, Sketch) : on met le lien et un export. Les données réelles d'utilisateurs dans les maquettes — on utilise des données fictives.

## Règle

Une maquette porte toujours sa date et l'écran qu'elle représente. Une maquette non datée devient vite trompeuse.
