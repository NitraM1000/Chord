# pages/copy/

Les formulations réutilisables : taglines et pitchs.

## Ce qu'on met ici

- `taglines.md` — les candidats, y compris ceux qu'on a écartés.
- `pitch-30s.md`, `pitch-2min.md`, `pitch-5min.md`.

## Ce qu'on ne met pas ici

Le texte de la landing (→ `pages/landing/`), le plan du deck (→ `pages/deck/`).

## Règle

Les trois pitchs racontent la même histoire à trois profondeurs différentes. S'ils se contredisent, c'est que le positionnement n'est pas au point — retour à `docs/positioning.md`.
