# assets/brand/

L'identité visuelle : couleurs, typographie, règles d'usage.

## Ce qu'on met ici

- `brand-guidelines.md` — la référence écrite.
- Les fichiers de police si la licence le permet.

## Ce qu'on ne met pas ici

Des polices sous licence commerciale qu'on n'a pas le droit de redistribuer. Le repo est public : on indique le nom de la police et où l'obtenir, on ne commite pas le fichier.

## Règle

Une couleur ou une police utilisée quelque part dans le projet doit figurer ici. Si elle n'y est pas, c'est qu'on a improvisé.
